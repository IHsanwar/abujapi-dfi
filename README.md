#  Aplikasi Manajemen Satpam Security

Aplikasi ini adalah sistem manajemen dan digitalisasi satpam untuk mempermudah tata kelola dan dokumentasi laporan satpam

##  Fitur Utama

- Manajemen anggota satpam
- Absensi harian anggota dengan limited-time QR code
- Riwayat absensi harian
- Pencatatan laporan online
- Fitur pencarian dan filter laporan
- Cetak laporan 

## 🛠 Teknologi yang Digunakan

- **Laravel** 
- **React JS**
- **Tailwind**
- **MySQL** 

##  Cara Instalasi

1. **Clone repositori ini:**

```bash
git clone https://github.com/IHsanwar/abujapi-dfi
```
2. **Install Dependencies**
```bash
composer install
```
3. **Jalankan Aplikasi**
```bash
php artisan main
```
## Cara Instalasi Frontend
1. **Clone repositori frontend

```bash
git clone https://github.com/fazaanggapr/abujapi-dfi
```
2. **Install Dependencies**
```bash
npm install
```
3. **Jalankan Aplikasi**
```bash
npm run dev
```
